All coding agents operating in this repository must:

1. Read `CODEX_MASTER_EXECUTION_PROMPT.md`.
2. Read the active sprint/ticket specification.
3. Read `docs/SOURCE_OF_TRUTH.md`.
4. Inspect existing code before editing.
5. Implement only the active scope.
6. Add/update tests for behavior changes.
7. Run lint, typecheck, tests, and build before claiming completion.
8. Update documentation/ADRs for architecture decisions.
